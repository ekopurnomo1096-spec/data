CARA PASANG (sekali saja)
1. Daftar gratis di geoapify.com (tanpa kartu kredit), buat project, salin API key.
2. Di Vercel: Project > Settings > Environment Variables
   Name : GEOAPIFY_KEY
   Value: (tempel API key)
   Environment: centang Production, Preview, Development
3. Deployments > titik tiga di deploy terbaru > Redeploy.
